## 比赛注意事项

### 📄 文档撰写要点

1. **格式统一**
   - 图片、表格、文本格式统一
   - 逻辑清晰（每段每节有概括）
   - 层级关系明确
   - 排版对称美观

2. **参考文献**
   - 80%选取近3年（24-26年）
   - 优先选择SCI 2区或CCF-B以上论文

### 🎨 PPT制作要点

1. **内容要求**
   - 参考论文内容
   - 不能出现大段文字
   - 每页不要太满

2. **排版要求**
   - 文字和图片对称排版
   - 不要太多颜色，保持统一风格
   - 避免花哨装饰元素

### ⚠️ 其他提醒

1. **AI生成内容**
   - AI写的内容需要人工审核
   - 关键术语要准确（如"卷积神经网络"）

2. **代码管理**
   - 及时在GitHub打卡提交代码
   - 保持代码仓库的整洁
